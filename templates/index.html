Academic notes

How to read these measurements

Real execution, not simulation

Every timing comes from executing parameterised SQL against PostgreSQL. Query plans are captured with EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON).

Not every query is comparable

Relational methods share filters and keyword predicates. HNSW and hybrid return semantic neighbours, while cached search changes state between runs.

Indexes are not always used

PostgreSQL may choose a sequential scan when a predicate is not selective. The plan is displayed exactly as executed.

Synthetic dataset

The 100,000 products are synthetic demonstration data, not real retail inventory. Prices are in INR.
