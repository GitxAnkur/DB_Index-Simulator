How to read the result

Real queries, real indexes

Database time only

The reported number is the time PostgreSQL spent executing the actual search query. Embedding time is not included.

Repeated searches are stable

Each search runs one query. Plans are not captured during interactive searches, so a second hidden execution cannot distort the timing.

Out-of-scope queries return nothing

If a query does not match the product catalogue, the application returns zero products instead of unrelated neighbours.

Synthetic dataset

The 100,000 products are synthetic demonstration data, not real retail inventory. Prices are in INR.
